# 泛型
## 泛型怎么写
```
// T，K指代泛型字母
class A<T>{
    void int Test<K>{}//泛型函数
}//泛型类
interface A<T>{}//泛型接口
```
## 泛型约束
使用where关键字 T，K指代泛型字母
1. 值类型 where T : struct
2. 引用类型 where T : class
3. 存在无参公共构造函数where T : new()
4. 某一个类本生或者派生类 where T : 类名
5. 某个接口的派生类 where T : 接口名
6. 另一个泛型类型或者派生类型 where T : K
### 多个约束
```
class Test<K,T> where T: class ,new() where K: struct
```
