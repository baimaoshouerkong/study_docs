# 特性
特性本质是个类，我们可以用特性类为元数据添加额外信息，方便反射
```
class MyCustomAttribute : Attribute
{
    public string info;
    public MyCustomAttribute(string info){
        this.info
    }
}
//使用
[MyCustom("1123")]
class A{

}
//反射
t.IsDefined(typeof(MyCustomAttribute),false); //后面的布尔表示是否去父类查看 
```
## 限制特性
[AttributeUsage(AttributeTargets,AllowMultiple,Inherited)]
1. AttributeTargets用在那些地方
2. AllowMultiple 是否允许多个用于同一个目标
3. Inherited 是否能派生和重写继承
## 自带特性
[Obsolete("",bool)] 过时,true直接报错，false警告
[CallerFilePath] 那个文件调用
[CallerLineNumber] 哪一行调用
[CallerMethodName] 哪个函数调用
[Conditional("")] 需要#define后才会运行
