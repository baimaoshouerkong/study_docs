# 类的初始化和字段
```
class Person{
    public const string title = "666";
    public int age;     
    public string name;
    public readonly int id;
    public static int heartNum = 1;
}
```
## 属性字段
这里简单说一下
* public 公开的字段，都可以访问和修改
* private 只有在类里才能修改
* protected 继承类可以访问到和修改
* static 是类所共用的一个字段，访问和修改使用`Person.heartNum`
* readonly 是一个只能被初始化的变量初始化后就不能修改了，我们只能再构造函数里对它进行修改
* const 只能声明的时候就赋值，只能用`Person.title`查看不能修改
## 构造函数
```
class Person{
    public int age;     
    public string name;
    public readonly int id;
    public static int heartNum = 1;
    //-----------------------------------
    public Person(int age){
        this.age = age;
        this.id = age;//只能再构造器里修改
    }
    static void Main(string[] args)
    {
        // var a = new Person();//空构造器,没写的话就是默认的,因为我们写了一个构造器所以这里会报错。
        var a = new Person(5); // 这个很标准如果我们想给其他的字段初始化呢
        var a = new Person(5){
            name = "Tom",
            // id = 5; 会报错的，应该这个是构造完进行的初始化
        };
    }
}
```
构造函数是一种特别的方法，不需要声明返回值。
## 访问字段
* get : 得到字段 
* set : 修改字段
* init: 特殊的set字段，只能再初始化的时候使用
```
class Person{
    public int age;     
    public string name;
    public readonly int id;
    public static int heartNum = 1;
    public int propA { get ; set; }
    public int propB { get ; init; }
    public int propC { 
        get {
            return propC
        } 
        set{
            //这里可以写一下一些验证的逻辑
        } 
    }

    //-----------------------------------
    public Person(int age){
        this.age = age;
        this.id = age;//只能再构造器里修改
    }
    static void Main(string[] args)
    {
        // var a = new Person();//空构造器,没写的话就是默认的,因为我们写了一个构造器所以这里会报错。
        var a = new Person(5); // 这个很标准如果我们想给其他的字段初始化呢
        var a = new Person(5){
            name = "Tom",
            propA = 1,
            propB = 1, // 不会报错
            // id = 5, 会报错的，应该这个是构造完进行的初始化
        };
        Console.WriteLine(a.propA); // 1
        a.propA = 2;
        Console.WriteLine(a.propA); // 2
    }
}
```
