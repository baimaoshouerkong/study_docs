# 类型引用
这里是一个很重要的知识点，也是经常会出错误的地方。
类型引用分为两种：
- 值类型：就是单纯的copy。
  * 整型
  * 浮点型
  * 布尔型
  * char型
  * struct结构体
- 引用类型：通过某个对象来引用类型。
  * class，interface，delegate，record声明的对象
  * C#还提供了dynamic，object，string三种特殊的引用类型。
```
object obj1 = new object(); // 定义一个object类型的变量obj1，并创建一个新的对象实例
object obj2 = obj1; // 定义一个object类型的变量obj2，并将obj1的引用赋值给obj2
Console.WriteLine(object.ReferenceEquals(obj1, obj2)); // 输出True，说明obj1和obj2引用的是同一个对象实例
int a = 0;
int change(int c) => {
    c = 1; // 改变c的值
    return c; // 返回c的值
}; // 定义一个方法change，改变变量a的值
Console.WriteLine("{0} + {1}", change(a), a); // 输出1 + 0，说明a的值没有改变，因为a是值类型，传递的是值的副本，而不是引用
object o1 = null;
// int a = null; // 不能将null赋值给值类型变量a，因为值类型必须有一个有效的值
int? a = null; // 定义一个可空类型的变量a，并赋值为null，表示a没有值
```
