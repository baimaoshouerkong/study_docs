# 类型转换
## 用法
```
float a = 1.0f;
double b = 1.0d;
// f = d;错误
f = (float)d; // 正确，double类型可以显式转换为float类型
d = f; // 正确，double类型可以隐式转换为float类型
int i = 1;
short s = 2;
// i = s;错误
i = (int)s; // 正确，short类型可以显式转换为int类型
s = (short)i; // 正确，int类型可以显式转换为short类型
```
## 自定义类型转换
C# 允许在自定义类型中定义 implicit 或 explicit 操作符，实现自定义类型之间的隐式或显式转换。
```
public class Fahrenheit
{
    public double Degrees { get; set; }
    public static implicit operator double(Fahrenheit f) => f.Degrees;
    public static explicit operator Fahrenheit(double d) => new Fahrenheit { Degrees = d };

    
    public static void Main(string[] args)
    {
        Fahrenheit a = new Fahrenheit { Degrees = 32 };
        double g = a; // implicit conversion
        Fahrenheit b = (Fahrenheit)g; // explicit conversion
    }
}

```
## 装箱拆箱
值类型（如int、struct）存储在栈上，引用类型（如object、class）存储在托管堆上
装箱：值类型 → 引用类型
拆箱：引用类型 → 值类型（必须显式）
