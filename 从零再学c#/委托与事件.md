# 委托
## 委托定义
```
// delegate 返回值 委托名(参数形式)
delegate void MyDelegate(int a);
```
## 使用委托需要初始化
```
MyDelegate md = null;
MyDelegate md = new MyDelegate(function);
MyDelegate md = function;
```
## 委托可以一次执行多个函数
```
MyDelegate md = null;
md += function1;
md += function2;
```
## 委托执行
```
md(1);
md.Invoke();// 一般情况不这么写
md?.Invoke();// 一般这么写
```
## System委托
```
Action<> 无返回值委托，泛型为参数列表，16个参数
Func<> 无参数委托，泛型为返回值，最后一个为返回值，其他是参数，一共17个
```
# 事件
## 事件是什么
事件是基于委托的存在，事件是委托的安全包裹，让委托更有安全性，事件是一种特俗的变量类型。
他只能存在于类接口或者结构体中
## 定义事件
```
event 委托类型 事件名;
```
## 事件相对委托的区别
1. 事件不能在类外复制和调用（但是可以加减）
