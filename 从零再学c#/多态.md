# 多态
## new
使用new关键字会覆盖继承的方法
```
class Father
{
    public void Speak()
    {
        Console.Write("111");
    }
}
class Son : Father
{
    public new void Speak()
    {
        Console.Write("222");
    }
}
Father a = new Son();
a.Speak();//"111"使用父类方法
(a as Son).Speak();// "222"
```
## virtual，override和base
```
class Father
{
    public virtual void Speak()
    {
        Console.Write("111");
    }
}
class Son : Father
{
    public override void Speak()
    {
        base.Speak(); //父类的方法
        Console.Write("222");
    }
}
```
