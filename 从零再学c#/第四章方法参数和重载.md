# 方法参数和重载
## 三个很重要的引用关键字
* ref ： 将一个参数变成引用类型，需要初始化，方法内可以不对ref声明的变量进行操作,使用方法时要加上ref
```
int check(ref int a){
    a = 1;
    return 0;
}
int a = 1;
check(ref a);
```
* out ： 将一个参数变成引用类型来输出，不需要初始化，方法内一定要对out声明的变量进行操作，使用方法时要加上out
```
int check(out int a){
    a = 1;
    return 0;
}
int a;
check(out a);
```
* in : 将一个参数变成引用类型但是只读，需要初始化,方法内不能对修改in声明的变量，使用时可以不加上in
```
int check(in int a){
    // a = 1;
    return 0;
}
int a = 1;
check(in a);
check(a);
```
## params 关键字
params关键字声明的变量一定要在最后一个
```
int sum(int a,int b int c,params int[] numbers)
```
## 默认参数
和python一样，默认参数后面只能跟默认参数
```
int A(int a ,int b = 1,int c = 1)
```
## 方法的重载
方法名字相同时，参数个数和参数类型，只要有不同就可以了
```
int A(int a)
int A(int a ,int b)
int A(int a,float b)
```
