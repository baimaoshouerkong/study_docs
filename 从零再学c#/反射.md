# 反射
## Type
### 获取Type
* object的GetType()方法
* typeof(类名)
* 通过类名（必须包含命名空间）
### 得到类的程序集
type.Assembly
### 公共成员
```
MemberInfo[] infos = t.GetMembers();
for(int i = 0; i < infos.Length; i++){
    Console.WriteLine(infos[i]);
}
```
### 构造函数
```
ConstructorInfo[] ctors = t.GetConstructors();// 获得所有
ConstructorInfo info = t.GetConstructors(new Type[0])；//无参
info.Invoke(null);
ConstructorInfo info1 = t.GetConstructors(new Type[]{typeof(int)})；//有参
info1.Invoke(new object[]{2});
ConstructorInfo info2 = t.GetConstructors(new Type[]{typeof(int)，typeof(string)})；//多参
info1.Invoke(new object[]{2,"11"});
```
### 成员变量
```
FieldInfo[] fieldInfos = t.GetFields();//所有
FieldInfo Info = t.GetFields("j");//指定
Console.WriteLine(Info.GetValue(test));// 获取对象的值
info.SetValue(test,100);//修改值
```
### 方法
```
MethodInfo[] methods = t.GetMethods();//所有
MethodInfo methods = t.GetMethods("函数名",new Type[]{typeof(int)});//某个具体函数
methods.Invoke(对象，new object[]{1});
```
