# 协变逆变
## 什么是协变逆变
### 协变
和谐的变化
如子类变成父类
### 逆变
逆常规的变化
如父类变成子类
## 协变逆变是用来形容泛型的。
* 协变 out
* 逆变 in
## 作用
### 返回值和参数
#### out
out修饰的泛型只能作为返回值
```
delegate T TestOut<out T>();//正确
delegate T TestOut<out T>(T t);//错误
```
父类泛型委托装子类
#### in
in修饰的泛型只能作为参数
```
delegate T TestIn<in T>();//错误
delegate T TestIn<in T>(T t);//正确
```
子类装父类
